# 临语 iOS 测试客户端

使用系统 WKWebView 加载临语 HTTPS 测试服务，持久保存本机网站数据。最低 iOS 15，arm64 iPhone/iPad。

Actions 构建产物 Lintalk-0.3.1-unsigned.ipa 是真实编译的 iOS 应用，尚未签名，不能直接安装。需交给签名服务处理，再进行真机验证。签名时保持 Bundle ID 稳定，避免更新后丢失原应用数据。

支持范围取决于当前聊天网页；不包含后台推送。不要清除应用数据。首次登录绑定当前应用，不能直接复用已绑定其他浏览器的测试账号。

没有内置账号、私钥或 TLS 绕过。签名平台是否接受未签名 IPA 需由平台确认。
